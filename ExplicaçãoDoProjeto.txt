“Meu projeto é uma análise de dados de Recursos Humanos. Usei Python com as bibliotecas pandas e matplotlib para analisar uma planilha CSV com registros de funcionários entre 2018 e 2023. Primeiro, organizei os dados e tratei informações inconsistentes, como idades fora de uma faixa plausível. Como a base registra os funcionários em diferentes snapshots ao longo do tempo, usei o snapshot mais recente para analisar a situação atual. Depois, calculei informações como salários por departamento, situação dos funcionários, admissões por ano e avaliações conforme as horas de treinamento. Por fim, criei gráficos para facilitar a visualização. Os resultados mostram padrões nos dados, mas a comparação entre treinamento e avaliação não prova que um cause o outro.”
